Counting method

  • Unit: individual mentions within the report, including its title, headings, and implementation lists.
  • Explicit: the vocabulary term, its stated abbreviation, or a normal grammatical form. For example, “LLMs,” “RAG,” “embeddings,” and “grounded” count. “Generative Artificial Intelligence (GenAI)” counts once, not twice.
  • Implicit: a manually identified passage describing the concept without naming the vocabulary term. Implicit counts are interpretive, not keyword-search results; another reviewer may classify borderline passages differently.
  • An implicit reference is not also counted as explicit for the same term in the same passage. Different terms can be counted in the same passage.
  • The four areas are the introduction (including the report title), software engineering, enterprise knowledge management, and customer support and operations.

Implicit-reference evidence

  • Semantic search — knowledge management (3): a query converted to an embedding and matched against documents; “semantic vector search”; and vector databases used for “similarity search.” These describe meaning-based or vector-similarity retrieval without using the exact phrase “semantic search.”
  • Tool calling — customer support (2): agents executing backend actions through “tool-use APIs”; and “executing external API calls securely.”
  • AI agent — customer support (2): “an agent” misinterpreting an input and taking subsequent automated actions; and Intercom Fin described as an autonomous “AI customer service agent.”
  • Evaluation — software engineering (1): “automated verification” using test runners and linters. This is a related check on generated code, rather than a formal evaluation of the entire AI application.

Zero does not prove a concept is absent in every possible interpretation. In particular, training, security, and retrieval references were not automatically treated as fine-tuning, guardrails, or RAG.
