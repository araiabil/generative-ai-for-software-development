# GenAI Application Development Vocabulary


| Generative AI (GenAI) | AI that creates content, such as text, images, audio, or code, based on patterns learned from data. |
| Large language model (LLM) | A model trained on large amounts of text that can generate and transform language. |
| Token | A unit of text a model processes. A token might be a word, part of a word, punctuation, or other text. |
| Context window | The maximum amount of text, measured in tokens, that a model can consider in a single request, including input and generated output. |
| Prompt | The instructions and information given to a model to guide its response. |
| System instruction | A high-priority instruction that defines how an application wants the model to behave. |
| Inference | The process of running a trained model to produce an output from an input. |
| Temperature | A setting that influences how varied a model’s output can be; lower values generally make responses more predictable. |
| Embedding | A numerical representation of content that captures aspects of its meaning and can be used to compare it with other content. |
| Vector database | A database designed to store and search embeddings, often to find content similar to a user’s query. |
| Semantic search | Searching for information by meaning rather than relying only on exact keyword matches. |
| Retrieval-augmented generation (RAG) | A technique that retrieves relevant information from external sources and supplies it to a model when generating an answer. |
| Grounding | Connecting a model’s response to supplied or retrieved evidence, such as documents or database records. |
| Hallucination | A model-generated claim that is false, unsupported, or invented but may sound plausible. |
| Fine-tuning | Further training a model on a specific dataset to adapt its behavior or performance for a task. |
| Tool calling | Allowing a model to request an external function, API, or service to perform an action or obtain information. |
| AI agent | An application that uses a model to help decide and carry out multiple steps toward a goal, often using tools. |
| Guardrail | A rule or control designed to reduce unsafe, unauthorized, or unwanted application behavior. |
| Prompt injection | An attempt to manipulate an AI application by placing instructions in content the application reads, such as a webpage or document. |
| Evaluation | Testing an AI application against defined criteria, such as accuracy, usefulness, safety, cost, and response time. |
